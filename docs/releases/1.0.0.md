# OpenChamber LingXiFox 1.0.0

LingXiFox 1.0.0 is the first formal LingXi desktop release. It uses OpenChamber 1.20.0 as its upstream base and was published for macOS arm64 on 2026-08-26.

## Source

- Release tag: `lingxi-v1.0.0`
- Release commit: `092737d3f5860111172aa0900a09ecd58a53b0ca`
- Upstream tag: `v1.20.0`
- Upstream commit: `52ee878669867d5cc415f7da7bda1808d51fdf5d`

The public tag is the source record. The binaries do not embed an attestation tying their bytes to a clean checkout, so this record does not claim one.

## Distribution

The GitHub Release contains the arm64 DMG and updater ZIP, `latest-mac.yml`, public SHA-256 checksums, and a documentation source archive. The app used Apple Development signing and was not notarized.

Exact filenames, byte sizes, SHA-256 values, and updater SHA-512 values are in [the machine record](../../.lingxi/releases/1.0.0.yml).
