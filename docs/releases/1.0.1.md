# OpenChamber LingXiFox 1.0.1

LingXiFox 1.0.1 moves the desktop product to the OpenChamber 1.21.0 upstream base while retaining LingXi's independent product version and identity.

## Source migration

- Upstream commit: `ad7fd356339ccc5c9af5af1a6786662572d53ed0`
- DEV integration source: `6afd22ca6ff203980735e870737b3871b8093e60`
- Legacy release preparation: `a83fd4cfbd51d6bacb21a134777afcf31ffbe079`
- Canonical DEV source anchor: `65492ce5d5e89aaf4475f309b0ca24bf4cb0300d`

The canonical anchor differs from the DEV integration source only by setting the Electron product version to `1.0.1`. Its build-relevant paths match the legacy release preparation commit. Run:

```bash
bun run release:lingxi:parity a83fd4cfbd51d6bacb21a134777afcf31ffbe079 65492ce5d
```

## Candidate evidence

The machine record contains a verified local macOS arm64 candidate: DMG, ZIP, blockmaps, updater manifest, and checksums. It uses Apple Development signing and is not notarized. Those files do not contain a source commit attestation, so their exact binary build commit remains unverified.

Windows x64 and Linux x64 passed native dry-run [33072947155](https://github.com/LingXiFox/openchamber-lingxi/actions/runs/33072947155) from source commit `17c1e86f275066919214bf239f69e54c947ed057`. Both packaged apps passed native-module verification and startup smoke tests. GitHub Actions then downloaded the uploaded artifacts, matched their pre-upload digests, verified the final inventory, and wrote `SHA256SUMS.txt`. The assembled artifact was downloaded again and its checksums were verified locally.

Formal run [33074561221](https://github.com/LingXiFox/openchamber-lingxi/actions/runs/33074561221) rebuilt and round-tripped Windows and Linux from immutable Build Source `fe5688c69377c26c64ae0a322b333243399aa19f`. The release operator combined those exact bytes with the byte-verified local macOS candidate, generated a new full checksum file, and verified the exact 11-asset Draft inventory through a clean download before publishing.

OpenChamber LingXiFox 1.0.1 is published at [GitHub Releases](https://github.com/LingXiFox/openchamber-lingxi/releases/tag/lingxi-v1.0.1). Windows installers remain unsigned. The macOS artifacts use Apple Development signing and are not notarized.

The general Docs Source release hook initially appended a non-contract archive after publication. The release was returned to Draft, the archive was backed up and removed, and [PR #20](https://github.com/LingXiFox/openchamber-lingxi/pull/20) prevents future `lingxi-v*` releases from receiving that extra asset. The final published inventory again matches `SHA256SUMS.txt` exactly.

Exact macOS artifact metadata and target status are in [the machine record](../../.lingxi/releases/1.0.1.yml).
